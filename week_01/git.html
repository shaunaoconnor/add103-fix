Git and GitHub

1. Understanding Git and GitHub

Git is like using Google Docs to create and change a document. GitHub is like Google Drive where I would locate that document and other documents.

2. VS Code Source Control Process

Click the Source Control icon (branch) to see all files under Changes. Hover over files needed in snapshot to move to Staged Changes. Click text box named Message at the top and type what was changed in this version. Like if I need to fix a typo. Commit the snapshot by saving changes locally to review later if needed. Sync with GitHub to save it in the repository.
